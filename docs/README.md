# Documentation

This folder contains supporting documentation for the **FPGA Pong in VHDL** project.

## Files

- **Final_Proj_Report.pdf** — Technical report describing the design, implementation, and testing of a two-player Pong game built in VHDL on the DE10-Lite FPGA board.

## Overview

The project was developed as a modular digital design in VHDL and includes:

- VGA synchronization and video output
- Paddle control
- Ball motion and collision detection
- Scorekeeping logic
- Seven-segment display integration
- Reset and win-state behavior
