# Documentation

This folder contains supporting documentation for the **FPGA Pong in VHDL** project.

## Included File

- **Final_Proj_Report.pdf** — IEEE-style technical report describing the design, implementation, testing, and hardware demonstration of a two-player Pong game built in VHDL for the **DE10-Lite** FPGA development board.

## Project Summary

The project implements a two-player Pong game in **VHDL** using a modular digital design approach. The report documents the major subsystems used in the project, including:

- VGA synchronization and video output
- Paddle control logic
- Ball motion and collision detection
- Scorekeeping logic
- Seven-segment display integration
- Reset and win-state behavior

## Notes

The technical report provides additional detail on the project architecture, Quartus schematic integration, module-level design, hardware validation, and observed limitations during testing.
